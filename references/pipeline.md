# Optional CI

Apply only when requested. Reuse project commands, package manager, and policy. Select changed application code and affected tests; expand to the module when diffs cannot guide selection.

Version configuration, dependencies, and agreed criteria. Use disposable services; retain logs/reports on failure. Invalidate caches after revision/configuration changes.

Implement the main checklist/classifications as gates. Verify known regressions, tool errors, and empty collection. Claim integration after verified configuration/execution; merge enforcement depends on provider rules.
